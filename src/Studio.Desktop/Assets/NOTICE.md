# Product-image source

The EXW1 base and remote images are cropped and resized from the original SMC image:
https://www.smcworld.com/assets/newproducts/en-jp/exw1/images/02-r.jpg

Product page: https://www.smcworld.com/newproducts/en-jp/22/exw1/

The photos have not been redrawn or generated. The white external background was removed. These are EXW1 family reference photographs, not a verified photograph of the eventual base/remote part numbers. The application does not assert that the depicted base is a specific BMT variant. SMC trademarks and product-image rights remain with their owner; the repository software license does not relicense these images. This is a community prototype, not an official SMC Corporation release.
