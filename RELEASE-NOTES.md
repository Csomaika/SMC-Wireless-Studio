Első telepíthető Windows x64 demókiadás.

- Hét működő, magyar nyelvű nézet az elfogadott sötét/kék dizájnnal.
- Tíz demó remote, átnevezhető eszközök és I/O-jelek.
- Kézi I/O, automatikus szenzorszimuláció, kapcsolatvesztési próba.
- Szerkeszthető és futtatható lépéssorok, 10/20/50/100 ms célciklus és mért időzítés.
- Projektmentés, import/export, eseménynapló és CSV.
- MSI Install / Update / Repair gombokkal; későbbi verziók frissíthetők kézi eltávolítás nélkül.
- Appon belüli Update: GitHub-kiadás ellenőrzése, MSI-letöltés és SHA-256 ellenőrzés.

A kiadás kizárólag szimulációt végez, valódi EXW1-kimenetet nem kapcsol. A termékképek gyári EXW1 családképek. A telepítő még nincs Authenticode-tanúsítvánnyal aláírva. Telepítési cél: Windows 10/11 x64; az automatizált ellenőrzés Windows Server 2022-n fut.
